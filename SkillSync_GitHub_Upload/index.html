SkillSync · Role-profile comparison: This browser-based tool compares skills extracted from the uploaded resume PDF with a reference profile for the selected career role. Role profiles represent typical baseline skills, not live or universal employer requirements. A “missing” skill means it was not detected in the PDF; it does not prove the candidate lacks that skill. Review extraction and alternate wording before drawing conclusions. PDF text and OCR processing run in this browser tab; the PDF/OCR libraries are downloaded from public CDNs, but resume text is not sent to those library providers. OCR can read printed labels near graphic icons, but cannot reliably identify a logo-only icon with no readable label. The current role-profile workflow does not display exact lines from a specific job description.
